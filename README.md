## 项目技术栈

前端主要技术栈：
Vue3、Nuxt4、Vite、Pinia、TypeScript、Tailwind CSS、SCSS

后端主要技术栈：
JDK21、SpringBoot 3+、Mybatis Plus、Mysql

## 服务启动

### 打包

使用maven打包命令

```shell
mvn clean package
```

### 部署运行

将打包好后jar包上传到服务器，然后使用 `java -jar` 命令启动即可
